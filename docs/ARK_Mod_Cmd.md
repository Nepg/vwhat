# 方舟服务器常用

## 管理员指令

- 开启管理员权限（`<Password>`为服务器管理员密码）

  ```bash
  EnableCheats <Password>
  ```

- 存档

```bash
  admincheat saveworld
```

- 消灭所有野生恐龙

```bash
  admincheat DestroyWildDinos
```

- 消灭玩家面前选中目标（生物、实体、建筑结构）

```bash
  admincheat DestroyMyTarget
```
